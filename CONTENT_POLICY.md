# Politica de Conteudo Publico

Este repositorio publico existe para dar aos jogadores acesso rapido ao material de mesa sem revelar bastidores do Mestre nem redistribuir obras protegidas.

## Permitido no Git publico

- Textos autorais de apresentacao da campanha.
- Resumos de regras de mesa sem reproduzir livros comerciais.
- Guias de criacao de personagem escritos para esta mesa.
- Lore ja revelado ou seguro para jogadores.
- Handouts criados para exibicao aos jogadores.
- Imagens autorais ou explicitamente aprovadas para uso no portal.

## Fora do Git publico

- PDFs comerciais de Conan, SWADE, GURPS, D&D ou outros sistemas.
- Arquivos de trabalho grandes: PSD, AI, videos, temporarios e exportacoes brutas.
- Notas de Mestre, segredos de faccao, clocks, cenas futuras e documentos de sessao privada.
- Atalhos `.gdoc`, pois eles nao preservam o conteudo textual no Git.

## Regra pratica

Se o texto resolve uma duvida de jogador sem estragar uma descoberta futura, pode entrar na wiki. Se revela bastidor, solucao de misterio, estatistica completa de inimigo ou material licenciado, fica fora.
