# Creditos e Atribuicao

As imagens em `docs/assets/` foram selecionadas a partir do acervo local de Conan Legacy para uso como handouts e apoio visual dos jogadores.

## Arquivos publicados

- `cover.png`: arte de capa/portal do acervo Conan Legacy.
- `capa-swade.png`: arte de apoio ao material SWADE da campanha.
- `ponte-da-passagem.png`: handout de mesa.
- `torre-khar-volun.png`: handout de mesa.
- `texto-de-abertura.png`: handout de abertura.

## Nota

Este repositorio e material de fa, sem finalidade comercial. Nenhum PDF comercial foi publicado no Git.
